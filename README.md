<b>
  <h1>
    Expense Tracker System (C)
  </h1>
</b>

A simple console-based Expense Tracker built using C and File Handling.

<b>Features</b>

* Add new expenses with category
* View all recorded expenses
* Calculate expense summary:

  * Total Expenses
  * Average Expense
  * Highest Expense
  * Lowest Expense
* Clear all expense records
* Data stored permanently using file handling (`expenses.txt`)

<b>Technologies Used</b>

* C Programming
* File Handling
* Arrays
* Functions

<b>How to Run</b>

1. Compile the program:

```bash
gcc expense_tracker.c -o expense_tracker
```

2. Run the program:

```bash
./expense_tracker
```

<b>Sample Categories</b>

* Food
* Travel
* Bills
* Shopping
* Entertainment
